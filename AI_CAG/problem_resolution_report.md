# CAG系統項目分類問題解決報告

## 用戶問題描述
用戶反映：系統將醫療費用錯誤地歸類到慰撫金項目下，而不是分別識別每個醫療費用項目並正確分類。

**原始問題輸出示例：**
```
慰撫金部分包含了: 460元、81,356元、2,290元等醫療費用
```

**期望輸出：**
```
醫療費用: 460元、81,356元、2,290元、476,103元、53,804元、4,280元、45,500元
看護費用: 391,600元  
交通費用: 49,299元
車輛修理費: 50,250元
工作損失: 292,160元
未來勞動力損失: 6,339,232元
復健費用: 510,000元
慰撫金: 500,000元
```

## 問題根因分析

### 1. 項目提取邏輯不精確
- **問題：** 排除關鍵詞過於嚴格，錯誤排除了正確的賠償項目
- **表現：** 4,280元、45,500元等醫療費用被誤判為非求償項目

### 2. 計算基礎金額誤識別  
- **問題：** 每日2,200元（計算基礎）被錯誤識別為獨立求償項目
- **表現：** 系統無法區分計算基礎與實際求償金額

### 3. 缺乏精確的項目分類機制
- **問題：** 沒有基於上下文的智能分類功能
- **表現：** 無法根據具體描述正確歸類到對應的費用類別

## 解決方案實施

### 1. 優化金額提取邏輯
```python
# 修復排除關鍵詞邏輯

    '日薪', '年度所得', '月收入', '時薪', '學歷', '畢業',
    '名下', '動產', '總計', '合計', '共計', '小計',
    '包括', '其中', '包含',  
    '所得', '薪資所得', '年收入', '月薪', '底薪', 
    '此有', '可證', '為證', '收據', '發票', '證明',
    '經查', '查明', '經審理'
]

# 添加強制包含關鍵詞
force_include_keywords = [
    '慰撫金', '修理費用', '薪資損失', '勞動力減損', '復健費用',
    '醫療費用', '看護費用', '交通費用', '工作損失'
]
```

### 2. 排除計算基礎金額
```python
# 精確判斷計算基礎
is_calculation_base = ('每日' in context and ('計算' in context or '以' in context))
# 特殊處理總結性描述
if '一共' in context or '總計' in context or '合計' in context:
    is_calculation_base = False
```

### 3. 實現智能項目分類
```python

    }
```

## 技術改進亮點

1. **上下文智能分析：** 基於50字符上下文進行語境判斷
2. **多層級過濾機制：** 包含詞 → 強制包含 → 排除詞 → 計算基礎判斷
3. **正則表達式優化：** 使用`[^。]*?`限制匹配範圍，避免跨句匹配
4. **去重機制：** 防止同一金額被重複分類
5. **備用策略：** 當標準格式識別失敗時，啟用簡單去重邏輯
