# 添加千分位逗號格式化功能

## 需求

用戶希望所有金額都能自動格式化為千分位逗號格式,例如:
- 53122元 → 53,122元
- 70000元 → 70,000元
- 156000元 → 156,000元
- 600000元 → 600,000元

## 實現方式

### 1. 修改`_fix_mixed_amount_format()`函數 (line 1391-1406)

在現有的中文數字轉換功能基礎上,添加純阿拉伯數字的千分位格式化:

```python
# 處理沒有千分位逗號的純阿拉伯數字（如：53122元 → 53,122元）
def add_thousand_separator(match):
    """為純數字添加千分位逗號"""
    num_str = match.group(1)
    # 如果已經有逗號就不處理
    if ',' in num_str:
        return match.group(0)
    # 轉成整數再格式化
    num = int(num_str)
    return f"{num:,}元"

# 匹配「純數字+元」的模式,但排除已經有逗號的
# 使用負向後顧確保前面不是逗號或數字
text = re.sub(r'(?<![,\d])(\d{4,})元', add_thousand_separator, text)
```

### 2. 在損害項目生成後應用格式化 (line 2304-2305)

在`_generate_llm_based_compensation()`返回結果前,調用`_fix_mixed_amount_format()`:

```python

result = self._verify_and_fix_amount_calculations(result)

# 格式化所有金額為千分位格式
result = self._fix_mixed_amount_format(result)

# 檢查結果是否包含預期格式

```

### 3. 結論段落已經有格式化 (line 1361-1365)

`generate_cot_conclusion_with_smart_amount_calculation()`已經調用了`_fix_mixed_amount_format()`,無需額外修改。

## 處理邏輯

### Regex說明: `(?<![,\d])(\d{4,})元`

- `(?<![,\d])` - 負向後顧斷言:確保前面不是逗號或數字
- `(\d{4,})` - 捕獲4位或更多數字
- `元` - 匹配"元"字

### 為什麼用4位數作為門檻?

- 小於4位數的金額(如215元)不需要千分位逗號
- 4位數或以上(如1000元、53122元)才需要格式化

## 特殊情況處理

1. **已有逗號的金額**: 不重複處理
   - 1,093,087元 → 保持不變 ✅

2. **少於4位數的金額**: 不添加逗號
   - 215元 → 保持不變 ✅

3. **中文數字混合**: 先轉換再格式化
   - 5萬3122元 → 5萬3,122元 ✅

4. **計算式中的金額**: 也會被格式化
   - （計算式：26,000元×6個月＝156000元）→（計算式：26,000元×6個月＝156,000元）✅
