# 修正LLM從範例抄金額的問題

## 問題描述

用戶測試發現,即使修正了遺漏項目和「未提供資訊」的問題,LLM生成的金額仍然是錯的:

### 實際輸入的金額:
1. 醫療費用：130,698元
2. 未來醫療費用：150,000元
3. 看護費用：368,000元
4. 就醫交通費用：25,885元
5. 醫療用品：45,749元
6. 營養品：18,000元
7. 不能工作損失：156,000元
8. 車輛維修：13,750元
9. 勞動能力減損：200,000元
10. 精神慰撫金：600,000元

### LLM實際生成的金額:
1. 醫療費用：**83,016元** ❌ (應該是130,698元)
2. 就醫交通費用：**12,790元** ❌ (應該是25,885元)
3. 看護費用：**525,000元** ❌ (應該是368,000元)
4. 慰撫金：**1,300,000元** ❌ (應該是600,000元)
5. 其他項目：全部遺漏 ❌

## 根本原因

LLM**從prompt中的範例直接抄金額**,而不是從實際的「原始損害描述」中提取!

對比發現:
- 83,016元 = 範例2的醫療費用 (line 1964)
- 12,790元 = 範例2-1的就醫交通費用 (line 1974)
- 525,000元 = 範例3的看護費用 (line 2053, 2060)
- 1,300,000元 = 範例3的慰撫金 (line 1987, 2054, 2063)

**問題**: Prompt中的範例使用了**具體金額**作為示範,LLM誤以為這些是模板,直接套用。

## 解決方案

### 修改位置
- **文件**: `KG_700_CoT_Hybrid.py`
- **單原告prompt**: line 1959-1992, 2033-2066
- **多原告prompt**: line 2140-2156

### 1. 將範例中的具體金額改為變數/佔位符

#### 修改前 (❌ 錯誤):
```markdown
【標準輸出格式範例2】
（一）醫療費用：83,016元
原告因本次事故受傷就醫，支出住院開刀費用53,122元、復健科費用14,822元...合計83,016元。

【標準輸出格式範例3】
（五）慰撫金：1,300,000元
原告因本次車禍頭部遭受撞擊...故請求慰撫金1,300,000元。
```

#### 修改後 (✅ 正確):
```markdown
【標準輸出格式範例2】
（一）醫療費用：[所有細項總和]
原告因本次事故受傷就醫，支出以下醫療費用：[列出所有細項及金額]，合計[總金額]元。

【標準輸出格式範例3】
（X）慰撫金：[從原文提取的金額]
原告因本次車禍[從原文提取的具體傷勢和痛苦描述]，故請求慰撫金[金額]元。
```

### 2. 在錯誤範例中明確標示「不要抄金額」

#### 修改前:
```markdown
❌ 錯誤範例（缺少說明）：
（一）醫療費用：83,016元
（二）看護費用：525,000元
```

#### 修改後:
```markdown
❌ 錯誤範例1（缺少說明）：
（一）醫療費用：XXX元
（二）看護費用：XXX元  ← 沒有說明段落

❌ 錯誤範例2（從範例抄金額）：
（一）醫療費用：83,016元  ← 這是範例中的金額，不是本案的實際金額！
```

### 3. 在prompt開頭添加警告 (line 1907-1910, 2093-2096)

```markdown
🚨 **重要警告**：
- ❌ **絕對禁止從下方的範例中抄金額**！範例中的金額（如83,016元、12,790元、1,300,000元等）都是示意用的，不是本案的實際金額！
- ✅ **所有金額和描述都必須從上方的「原始損害描述」中提取**
- ✅ 範例只是用來說明格式，不是讓你抄內容的
```

### 4. 在檢查清單中添加檢查項 (line 2046)

```markdown
⚠️ **檢查清單**：在輸出前，請確認：
□ 是否每個項目都有說明段落？
□ 是否所有金額和描述都是從「原始損害描述」中提取的？（不是從範例中抄的）
□ 是否包含了慰撫金項目（如果原文有提到）？
```

## 關鍵教訓

**Prompt設計原則**:
1. ❌ **不要在範例中使用具體數字**,除非你希望LLM抄這些數字
2. ✅ 使用佔位符 `[金額]`、`[描述]`、變數 `X`、`Y` 等
3. ✅ 在prompt開頭明確告訴LLM「範例只是格式,不是內容」
4. ✅ 用醒目的符號(🚨、❌、✅)強調重要指示
